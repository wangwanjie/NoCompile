## NoCompile 0.2.10

本版本新增一键接入脚本，解决「接入改动不能提交、每次切换分支都要重新设置」的问题。

### 新功能

- **一键接入脚本 `nocompile_setup.py`**（位于 `NoCompile.app/Contents/Resources`）：在工程目录运行即可完成「拷贝 bundle」方式的全部接入，只作用于 App 类型 target 的 Debug 配置
  - Other Linker Flags 追加 `-Xlinker -interposable`；清空 `EXPORTED_SYMBOLS_FILE`（例如只导出 `_main` 的工程，可用 `--keep-exported-symbols` 保留）；关闭 `ENABLE_USER_SCRIPT_SANDBOXING`
  - Build Phases 末尾添加 Run Script「[NoCompile] Copy Bundle」
  - 在 `didFinishLaunchingWithOptions`、`applicationDidFinishLaunching` 或 SwiftUI `App` 的 `init()` 最前面插入加载代码，自动区分 Swift / Objective-C 与 iOS / tvOS / macOS、模拟器 / 真机
  - 所有改动都带标记，`--remove` 原样撤销，不影响工程里的其他改动；重复运行会跳过已接入的部分
- **CocoaPods 钩子**：`nocompile_setup.py --install-pod-hook` 在 Podfile 添加一个可以提交的 `post_integrate` 钩子。本机 `export IntegrateNoCompile=true` 后，`pod install` 会自动接入；未设置时自动撤销；没装 NoCompile.app 的同事不受影响

```bash
/Applications/NoCompile.app/Contents/Resources/nocompile_setup.py            # 在工程目录运行，接入
/Applications/NoCompile.app/Contents/Resources/nocompile_setup.py --remove   # 切换分支前撤销
```

### 升级提示

- 客户端修订号没有变化，已编译的 App 仍可正常热重载，无需重新编译

详见 [接入指南 · 一键接入脚本](https://github.com/wangwanjie/NoCompile/blob/main/Docs/Integration.md#一键接入脚本本地调试不提交)。
