## NoCompile 0.1.0

首个公开版本。NoCompile 是 iOS / macOS 热重载工具：修改代码并保存，几秒内就能在运行中的 App 看到效果，无需重新编译整个工程。

### 主要特性

- **多语言**：支持 Swift、Objective-C、C、C++
- **多平台**：支持 iOS 真机（USB）、iOS 模拟器、macOS App
- **零侵入**：业务代码不需要 import、调用，也不需要实现 `injected()`。注入后自动重建受影响的可见页面（UIKit / AppKit）
- **适配新版 Xcode**：从构建日志取模块命令，交给 `swiftc -###` 展开出单文件编译命令，不依赖 `EMIT_FRONTEND_COMMAND_LINES`，也不修改 Xcode 工具链
- **三层替换**：ObjC 方法替换、Swift vtable 覆写、符号重绑（C / C++ / Swift 静态函数）
- **安全防护**：检测到内存布局变化时拒绝注入；保留静态状态（单例不重建）；拦截 `+load` 中的重复 swizzle；修正注入后的类型判定
- **控制台**：已连接 App、注入记录与耗时统计、可过滤可搜索的实时日志
- **偏好设置**：保存即注入 / 手动注入、头文件监听、排除路径、失败通知、提示音、登录启动等；App 端行为实时下发
- **自动更新**：基于 Sparkle

### 接入

1. App 的 Debug 配置添加链接参数 `-Xlinker -interposable`
2. 通过 SPM 依赖 `NoCompile` 库（仅 Debug 生效）
3. 打开 NoCompile，选择工程，在 Xcode 中运行 App

详见 [接入指南](https://github.com/wangwanjie/NoCompile/blob/main/Docs/Integration.md) 与 [示例工程](https://github.com/wangwanjie/NoCompile/tree/main/Examples/NoCompileExample)。

### 已知限制

- 增删存储属性、给非 final 类增删方法需要重新运行 App（NoCompile 会检测并拒绝注入）
- SwiftUI 需要配合 `@ObserveInjection` 触发重绘
- 暂不兼容 Whole Module Optimization 与编译缓存（Debug 默认关闭）

系统要求：macOS 12 及以上，Xcode 15 及以上。
