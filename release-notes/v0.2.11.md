## NoCompile 0.2.11

### 修复

- **Podfile 钩子接入后看不到链接参数和 Run Script**：启用了 `cocoapods-arm64-to-sim` 等会在 `post_integrate` 中保存工程的 CocoaPods 插件时，插件在 Podfile 钩子之后执行，用内存中的旧工程覆盖了 `nocompile_setup.py` 对 `project.pbxproj` 的修改，只剩 AppDelegate 里的加载代码。`--install-pod-hook` 生成的钩子改为在 `pod install` 成功结束、所有钩子执行完后再接入

### 升级提示

- 用 0.2.10 生成或照抄了旧钩子的 Podfile，需要换成新钩子：删掉旧的 `post_integrate` 钩子后重新运行

```bash
/Applications/NoCompile.app/Contents/Resources/nocompile_setup.py --uninstall-pod-hook   # 去掉带标记的旧钩子；手动粘贴的需手动删除
/Applications/NoCompile.app/Contents/Resources/nocompile_setup.py --install-pod-hook
```

- 客户端修订号没有变化，已编译的 App 仍可正常热重载，无需重新编译

详见 [接入指南 · 一键接入脚本](https://github.com/wangwanjie/NoCompile/blob/main/Docs/Integration.md#一键接入脚本本地调试不提交)。
