## NoCompile 0.2.0

### 新增

- **资源热重载**：保存 `.storyboard` / `.xib` 后自动用 ibtool 编译并下发，当前可见的页面按新界面重建，之后打开的页面也使用新版本；替换 Asset Catalog 图片集或工程中的图片后，`UIImage(named:)` / `NSImage(named:)` 与 nib 中引用的图片立即返回新图。iOS 真机、模拟器与 macOS 均支持
- **新增源文件**：运行中新建的 Swift / Objective-C / C / C++ 文件保存后即可注入，已有文件可以直接使用其中的新类型与函数
- **更多接入方式**：支持 CocoaPods、Carthage；NoCompile.app 内置客户端 bundle，可运行时加载、拷贝进 App（支持真机）或通过 `DYLD_INSERT_LIBRARIES` 零代码接入
- 偏好设置新增「热重载界面与图片资源」开关，命令行新增 `--no-resources`

### 修复

- 代码注入后，界面来自 storyboard / xib 的页面会被清空：现在改为重新加载 nib，失败时保持原界面

### 已知限制

- 资源热重载只覆盖主 bundle；App 图标、颜色集、矢量图片、暗色等外观变体、`Localizable.strings` 需要重新运行 App
- SwiftUI 的 `Image("name")` 不经过 `imageNamed:`，不会拿到新图
- 新增的 Objective-C 类要被 Swift 使用，需要修改桥接头并重新构建

详见 [接入指南](https://github.com/wangwanjie/NoCompile/blob/main/Docs/Integration.md)。
