## NoCompile 0.2.12

### 修复

- **「拷贝 bundle」方式接入后工程编译失败**：`[NoCompile] Copy Bundle` 阶段报 `IDENTITY\357: unbound variable` 与 `Command PhaseScriptExecution failed with a nonzero exit code`。Xcode 用系统自带的 bash 3.2 执行 Run Script，在 UTF-8 环境下它会把紧跟变量名的中文全角字符当成变量名的一部分，`nocompile_copy_bundle.sh` 因此在签名完成后退出。已修复所有同类写法，并新增测试防止再次出现

### 升级提示

- 升级后直接重新编译即可，Run Script 调用的是 NoCompile.app 内的新脚本，工程无需改动
- 客户端修订号没有变化，已编译的 App 仍可正常热重载
