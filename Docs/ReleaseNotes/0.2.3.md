## NoCompile 0.2.3

### 新增

- **注入记录可清除**：「最近注入」标题行新增清除按钮；右键菜单可删除单条记录，选中后按 Delete 键同样可删
- **注入记录可预览与查看详情**：单击选中记录，按空格弹出预览，↑/↓ 切换，双击或回车打开详情（含完整失败信息，可复制），⌘C 复制选中记录
- **日志控制台快捷键**：⌘+ / ⌘- 缩放日志字号（会记住），⌘F 聚焦日志搜索框

### 优化

- 日志控制台支持跨行拖选与复制，不再只能逐条复制；追加日志为增量刷新，选择文字时不会自动滚动打断选区

### 修复

- 只含分类的 .m 文件注入后误报「未替换」
- 头文件变更后模块缓存过期导致 ObjC 重编出现无法重建的 fatal error（默认不再加 `-fno-validate-pch`）

> 升级后请重新编译运行接入了 NoCompile 的 App，CocoaPods / SPM / Carthage 接入的请同时把依赖更新到 0.2.3。

详见 [接入指南](https://github.com/wangwanjie/NoCompile/blob/main/Docs/Integration.md)。
